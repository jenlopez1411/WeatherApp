# WeatherApp 🌦️

A weather application built in **Swift (iOS)** that displays current weather information for cities using a weather API.

> This project provides a user-friendly interface to search and view weather data for any location, built as an iOS app using Swift and SwiftUI/UIKit.

---

## 📌 Features

- Fetches and displays **current weather data**
- Search weather by **city name**
- Shows details such as **temperature**, **conditions**, **wind**, **humidity**, etc.
- Designed with a clean and responsive UI
- Built with **Swift**, **SwiftUI / UIKit** *(depending on your implementation)*
- Uses an external weather API (e.g., **OpenWeatherMap**) for real-time data :contentReference[oaicite:1]{index=1}

---

## 🛠️ Built With

- **Swift** – iOS programming language  
- **Xcode** – IDE for iOS development  
- **SwiftUI / UIKit** – UI framework  
- **Weather API** – Weather data provider (e.g., OpenWeatherMap)
